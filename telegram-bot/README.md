# Telegram-бот для приёма заявок

Это Python-версия учебной демонстрации, первоначально написанной на Node.js. В личном чате бот предлагает две услуги — Telegram-бот или автоматизация. Затем задаёт один вопрос о задаче, показывает текст заявки и ждёт подтверждения. Кнопка «Отправить» сохраняет заявку в SQLite и возвращает её номер.

## Посмотреть диалог на компьютере

Откройте терминал в каталоге `telegram-bot`. Нужен Python 3 с модулем `sqlite3` из стандартной библиотеки. Проверено на Python 3.12.

```sh
python bot.py
python -m unittest -v test_bot.py
```

Обе команды работают офлайн и используют SQLite в памяти. В конце примера появится «Заявка №1 принята». Три теста проверяют подтверждение и длину описания, отмену в двух независимых диалогах, повтор обновления и повторную доставку ответа при имитации сбоя связи.

## Подключить своего бота

Передайте токен своего бота через переменную окружения `TELEGRAM_BOT_TOKEN` и запустите один экземпляр процесса. Адаптер использует long polling. Перед запуском отключите webhook этого бота, если он настроен.

```sh
python telegram_adapter.py
```

Начните личный диалог командой `/start`. Введите от 5 до 500 символов, затем нажмите «Отправить» или «Отменить». Команда `/cancel` удаляет текущий черновик на любом этапе.

Адаптер создаёт `requests.sqlite` в текущем каталоге. Другой путь можно указать в переменной `BOT_DB`. В таблице `requests` сохраняются номер, идентификатор чата, услуга, описание и дата подтверждения в UTC. Доступ к файлу нужен владельцу бота. Для остановки нажмите Ctrl+C.

При повторе последнего обновления бот использует сохранённый ответ. После обрыва связи пользователь может получить его повторно с тем же номером заявки. Подключение к реальному боту в проверку этой демонстрации не входило.
