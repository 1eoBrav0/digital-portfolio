# Отбор заказов из RSS-ленты FL.ru

Сценарий читает публичную RSS-ленту, отбирает заказы по пяти направлениям и выдаёт карточки в последнем узле. Для каждой карточки видны название, найденные направления, описание, ссылка и дата публикации. Если в заголовке указан бюджет, он попадёт в отдельное поле.

## Запустить в n8n

1. Создайте пустой workflow в своей установке n8n. В меню workflow выберите **Import from File** и откройте `fl-orders-n8n.json`.
2. Запустите workflow вручную. Узел «Лента FL.ru» запросит публичный адрес `https://www.fl.ru/rss/all.xml`. Для этого нужен доступ в интернет.
3. Откройте результат узла «Подходящие заказы». Вкладка **Output** покажет совпадения или сообщение о пустой выборке.
4. Для запуска по расписанию опубликуйте или активируйте workflow в своей версии n8n. Узел «Каждый час» срабатывает в начале часа по часовому поясу workflow или экземпляра n8n.

В файле четыре стандартных узла n8n. Ручной и часовой триггеры ведут в один RSS-узел, а затем в Code. Сценарий поставляется выключенным, без закреплённых записей, учётных данных и подключений к чужим аккаунтам.

## Что учитывает фильтр

- Ключевые слова охватывают Telegram-ботов, автоматизацию, сайты, изображения и дизайн, видео. Сначала фильтр ищет совпадения в заголовке и обращается к описанию только при отсутствии совпадений в заголовке.
- В живой ленте фильтр принимает адреса проектов FL.ru с числовым идентификатором. Повторы одного проекта убираются в пределах одного запуска. При следующем запуске проект может появиться снова.
- Вверху выдачи оказываются карточки с явной отметкой «для всех» в последних скобках заголовка. Затем учитываются совпадение в заголовке и дата. Метка отражает текст объявления. Условия отклика уточняются на FL.ru.
- Бюджет извлекается из выражения «бюджет: …» в заголовке. Если его там нет, поле остаётся пустым. Описание ограничено 800 символами.
- Поиск ограничен текущим содержимым RSS. Сценарий показывает результаты в n8n. Отправка откликов и уведомлений в него не входит.

## Проверка фильтра офлайн

Понадобится Node.js 20 или новее. Из каталога `n8n` выполните команду.

```sh
node --test filter.test.cjs
```

Тест читает JavaScript непосредственно из поставляемого workflow и подаёт ему вымышленные записи. Флаг `demo: true` позволяет проверить учебную запись без ссылки. Тест проверяет сортировку, выделение бюджета, удаление повторов, пустой результат и обработку учебной записи. Он не подключается к FL.ru или n8n. Работа живой ленты отдельно не проверялась.
