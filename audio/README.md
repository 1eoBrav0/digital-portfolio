# Обработка речи для подкаста — до и после

Демонстрационная работа Серафима Мельника. В исходной дорожке слышны гул и шипение. После очистки паузы становятся тише, а голос остаётся на том же месте. Обе версии длятся 11,254 с. Первые 0,85 с оставлены для прослушивания фона.

## Исходный материал

Авторский текст озвучен офлайн русским голосом Microsoft Irina. Для теста к голосу добавлены белый шум, гул 50 Гц и две его гармоники, 100 и 150 Гц. На обработку подан сохранённый файл `before.wav`. Чистая дорожка синтезатора нужна только при подготовке исходной смеси.

## Обработка и измерения

Профиль шума рассчитан по первым 0,70 с. В частотной области применены подавление стационарного шума и фильтр высоких частот с частотой среза 85 Гц. В конце выставлен уровень активных фрагментов с контролем максимального пика. Экспорт обеих версий — моно WAV, PCM 16 бит, 16 кГц.

| Показатель готового WAV | До | После |
| --- | ---: | ---: |
| Уровень фона в паузе 0,15–0,65 с, RMS, dBFS | −26,66 | −49,69 |
| Среднеквадратичный уровень активных фрагментов, dBFS | −21,88 | −20,00 |
| Максимальный уровень отсчёта, dBFS | −2,08 | −1,63 |

Фон в этой паузе снизился на **23,03 дБ**. RMS активных фрагментов рассчитан по окнам длительностью 30 мс с уровнем выше 12% максимального оконного RMS каждой версии.

## Воспроизведение проекта

Понадобятся Windows 10/11 с установленным голосом Microsoft Irina, Windows PowerShell 5.1, Python 3, NumPy и Pillow. Генератор фиксирует начальное значение для шума. Измерения рассчитываются из итогового PCM и выводятся в терминал. На другой версии системного голоса длительность и значения могут отличаться.

Команды для сборки WAV, обложки и видео из каталога проекта

```powershell
python -m pip install numpy pillow
.\reproduce.ps1 -OutputDirectory .\rebuilt -Video
```

Параметр `-Python` принимает путь к интерпретатору. Если нужны только WAV и PNG, опустите `-Video`. Исходный код обработки и построения обложки находится в [tools/render.py](tools/render.py), скрипты синтеза голоса и монтажа — в [tools/voice.ps1](tools/voice.ps1) и [tools/make-video.ps1](tools/make-video.ps1).
