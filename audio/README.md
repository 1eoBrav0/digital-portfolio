# Очистка голоса: до и после

В этом примере Денис читает фрагмент на русском языке. Для демонстрации к записи добавлены сетевой гул и ровный фоновый шум. Включите ролик на одной громкости. Сначала слышна зашумлённая версия, с 11,177 с повторяется та же запись после обработки. В первой паузе хорошо слышно, как изменился фон.

## Обработка

Исходную запись использовали целиком. К ней добавили 0,70 с перед началом, гул 50 Гц с двумя гармониками и широкополосный шум. Скрипт читает получившийся `before.wav`, оценивает амплитуду и фазу гула по вступительной паузе и вычитает три узкополосные составляющие. Затем по профилю этой же паузы он ослабляет постоянный шум и применяет фильтр высоких частот с частотой среза 55 Гц.

Обе версии содержат по 536 496 отсчётов и длятся 11,177 с. Формат — моно, WAV PCM 16 бит, 48 кГц.

| Измерение по готовому WAV | До | После |
| --- | ---: | ---: |
| Фон в одной и той же паузе (0,15–0,65 с), RMS, dBFS | −33,84 | −55,27 |
| RMS активных фрагментов, dBFS | −19,93 | −20,00 |
| Пиковый уровень отсчёта, dBFS | −4,74 | −5,12 |

Фон в измеренной паузе стал тише на **21,43 дБ**. Для оценки уровня активных фрагментов использовались окна по 30 мс, в которых RMS превышал 12% от максимального RMS окна в соответствующей версии.

## Повторная сборка

Потребуются Windows 10/11, Python 3 с пакетами NumPy и Pillow, а для ролика — Windows PowerShell 5.1. Из каталога этого проекта выполните команды ниже. В папке `rebuilt` появятся оба WAV, обложка и MP4.

```powershell
python -m pip install numpy pillow
.\reproduce.ps1 -OutputDirectory .\rebuilt -Video
```

Ключ `-Python` указывает путь к интерпретатору. Для сборки звука и обложки достаточно запустить команду без `-Video`. Сценарий использует включённый в проект исходный WAV и фиксированное начальное значение для генерации шума.
