# Ser Motion — вертикальная рекламная заставка

Самостоятельная демонстрационная работа: 30 секунд, 1080 × 1920, 30 fps, H.264/AAC. Шесть типографических сцен, плавное движение, переходы через затемнение, оригинальный синтезированный звуковой ритм. Текст читается без звука. Музыка и графика созданы для примера; чужие видео и аудиосэмплы не использованы.

Готовый файл: [ser-motion.mp4](ser-motion.mp4). Превью: [poster.png](poster.png). Сценарий: идея → смысл → ритм → форма → история → предложение показать свою идею. Каждая сцена занимает пять секунд.

Это пример motion-графики и экспортирования ролика, не доказательство опыта личной съёмки или монтажа разговорного видео клиента.

## Воспроизведение сборки

Нужны Node.js 20+, Python 3.11+, FFmpeg с libx264. Из `demand-lab`: `npm install`, `npm run assets`. Затем:

```sh
python motion/render.py --ffmpeg ffmpeg
```

Векторные исходники — `frames/*.svg`; генератор — `../build-assets.mjs`. Все надписи и цвета меняются там. Промежуточные видео и WAV создаются в `render-work/` и исключены из Git. Логотип Ser предоставлен владельцем. Автор демонстрации: Серафим Мельник, с использованием Codex.
