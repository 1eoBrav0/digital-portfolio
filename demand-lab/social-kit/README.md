# Ser Coffee — комплект графики

Вымышленная кофейная коллекция для демонстрации дизайна. Не коммерческий бренд и не выполненный заказ клиента. Утверждённый логотип Ser предоставлен владельцем; иллюстрация чашки, композиции и девять иконок созданы для этого проекта кодом в SVG.

| Файл | Формат | Задача |
|---|---|---|
| `post.png` / `post.svg` | 1080 × 1350 | Вертикальная публикация |
| `story.png` / `story.svg` | 1080 × 1920 | История с безопасными отступами |
| `cover.png` / `cover.svg` | 1920 × 768 | Широкая обложка, адаптация под площадку после согласования |
| `icons.png` / `icons.svg` | 1080 × 1080 | Обзор набора |
| `icons/*.svg` | viewBox 96 × 96 | Девять отдельных масштабируемых иконок |

SVG редактируются в векторном редакторе. Надписи оставлены текстом, шрифт Arial; при передаче в типографию потребуется согласованный шрифт и преобразование в кривые. Логотип — встроенный PNG, исходник владельца, а не векторная перерисовка. PNG предназначены для цифровых площадок; файлы не заявляются как готовые CMYK-макеты для печати.

Пересобрать: из родительской папки `npm install`, затем `npm run assets`. Никакие материалы заказчиков не использовались. Автор демонстрации: Серафим Мельник, с использованием Codex.
